# Google Slides opcional

Usar solo si el usuario también solicita una copia nativa o el entorno lo utiliza como editor. Seguir la habilidad Google Slides disponible. Importar una copia del modelo local o crear una presentación nueva; no depender de IDs de cuentas históricas. Actualizar todas las secciones y temas, exportar obligatoriamente a PPTX y PDF y comprobar que ambos mantienen contenido y diseño. Un enlace de Slides no sustituye esas entregas.

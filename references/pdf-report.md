# PDF

Exportar el PowerPoint final a PDF con las mismas diapositivas, rango, cifras y tema. Conservar tamaño y orientación. Si la conversión requiere cambiar fuentes, revisar el diseño resultante y corregirlo. Renderizar todas las páginas; comprobar texto extraíble cuando sea posible, número de páginas y ausencia de cortes o superposiciones. Una versión ejecutiva o análisis de días fuertes separado solo se agrega a pedido y no reemplaza el PDF principal.
